先理解轨迹，再对照真实波形。

本页参考用户提供的 47 秒 LTSSM 动画，独立编写交互与数据。所有波形均为确定性的教学示例，未导入 RTL、仿真器或真实 PHY 采样。访问日期：2026-11-17。

Rate = 5 才是 64 GT/s。PIPE Rate 的标准编码从 0 开始，Gen6 的代际编号不能直接用作 Rate 数值。
换速请求、PHY 完成、双向 TS0→TS1 是不同事件。Gen6 TS0 使用 PAM4 的两电平子集（NRZ-like），不意味着存在一个名为“NRZ/PAM4”的通用 PIPE 开关。

阅读本页的约定

  • 完整建链选择逐档演示路径；并不要求每条真实链路都必须依次驻留 Gen2/3/4/5 的 L0。
  • 32 GT/s 的 EQ TS2 用于传递 64 GT/s 预置参数；随后展示 64 GT/s 的 EQ Phase 0/1/2/3。双方进入各 phase 并非同时，本页只突出关键方向差异。
  • P2：Downstream 先 TS0 后 TS1；P3：Upstream 先 TS0 后 TS1。64 GT/s L0 使用 Flit Mode；低代际也可以在事先协商后使用 Flit Mode。
  • Phystatus、RxStatus 等绘制为握手示意。PCLK 是固定节拍图案，采样格经过压缩；波形宽度不表示规范时间或模拟信号频率。
  • 未建模：精确 TS 计数/EC 位、BER、EIEOS 插入、EQ Bypass/NEE、Retimer、多 lane、完整 SerDes message bus、超时规则，以及 TLP 接受、背压、未完成事务、排序和 ID 复用。
  • L0s 仅在 Gen5 Non-Flit 场景演示：Flit Mode 不支持 L0s。Gen6 的 L0p 涉及多 lane 宽度调节，本页尚未建模。Hot Reset、Disabled、Loopback 也是单独的选定路径；本页不作协议符合性判断。
